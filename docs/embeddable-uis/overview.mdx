# Permit Elements

<ProductOverviewLink href="https://www.permit.io/elements" label="Permit Elements" />

Add access-control UI to your application with prebuilt, embeddable components.
<br />

### What are Elements?

**[Permit Elements](/embeddable-uis/element/user-management)** are embeddable UI components for access control: user management, access requests, approvals, and audit logs.
Each element works against your Permit policy, so you can delegate parts of access control to your end users safely.

Elements features include:

<div className="list">
	<ul>
		<li>
			<span>
				Authentication with your own identity provider, configured through JWKS for your environment
			</span>
		</li>
		<li>
			<span>Responsive layouts for desktop and mobile screens</span>
		</li>
		<li>
			<span>
				Custom styling rules so you can match the look and feel of your site
			</span>
		</li>
		<li>
			<span>
				Embedding with a generated iframe snippet
			</span>
		</li>
	</ul>
</div>
