Learn what Permit Elements are, which elements exist, and where to start embedding one. This page is for developers and product teams who want to let their own end users manage access inside their application.

## What Permit Elements are \{#what-are-elements}

Permit Elements are embeddable UI components for access control: user management, access requests, operation approvals, and audit logs. You add an element to your application as an iframe. The element reads and changes data in your Permit environment, and your policy decides what each end user can see and do in it. The [permission levels](/embeddable-uis/permission-levels) you assign to your roles set those limits.

Every element supports:

- Sign-in with your own identity provider, verified through the JSON Web Key Set (JWKS) of your environment
- Layouts for desktop and mobile screens
- Custom colors, titles, and displayed fields, so the element matches your application
- Embedding with an iframe snippet that the Permit dashboard generates

![Permit Elements workflow: configure permission levels, theming, and user data in the dashboard, copy the iframe code, and embed the User Management element in an application](/img/elements/generic/overview.png)

## Available elements \{#element-types}

| Element | What end users do with it |
|---|---|
| [User Management](/embeddable-uis/element/user-management) | Invite users, assign roles, and review pending invitations and access requests. |
| [Audit Logs](/embeddable-uis/element/audit-logs) | See which user performed which action on which resource, and when. |
| [Access Request](/embeddable-uis/element/access-request) | Request a role they don't have. A reviewer approves or denies the request in the User Management element. |
| [Operation Approval](/embeddable-uis/element/operation-approval) | Request approval for a single sensitive action, such as a large funds transfer. |
| [Approval Management](/embeddable-uis/element/approval-management) | Approve or deny operation approval requests. |

## Embed your first element

1. Create the element in the Permit dashboard and copy its iframe code. See [Embed Permit Elements](/embeddable-uis/embedding-elements).
2. Assign your roles to the element's permission levels. See [Permission levels](/embeddable-uis/permission-levels).
3. Log each user in to the element from your application before the iframe loads. See [Log users in to Permit Elements](/embeddable-uis/element-login).
