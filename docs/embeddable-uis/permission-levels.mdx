Permission levels decide what a user sees and can do in a Permit element, based on the user's role. This reference is for admins who configure elements in the Permit dashboard. It lists the five levels and explains how to assign your roles to them.

## How permission levels work \{#what-are-permission-levels}

Every element in Permit Elements, the embeddable UI components, has permission levels in its configuration form. You drag each of your roles into one level. A user's role decides the user's level in that element.

When you create an element, every level is empty, and all your roles start in **Hidden Roles**. Users whose roles stay in **Hidden Roles** don't see the element. If a user opens the element with such a role, the login fails with `INVALID_PERMISSION_LEVEL`. See [Login errors](/embeddable-uis/element-login#login-errors).

![A role named Admin being dragged into an empty permission level box labeled Drag roles here](/img/elements/levels.png)

## The five permission levels \{#5-permission-levels}

| Level | What users with a role in this level can do |
|---|---|
| **Level 1: Workspace Owner** | Assign any role, and add or remove users. |
| **Level 2: Manager** | Assign roles in levels 2 to 4, and add or remove users. |
| **Level 3: Viewer** | View the element. They can't make changes. |
| **Assignable Roles** (level 4) | Nothing in the element. They don't see the element, but Level 1 and Level 2 users can assign these roles to others. |
| **Hidden Roles** | Nothing. These roles don't appear in the element, and nobody can assign them from the element. |

The element form also has a **Default role to assign when adding new users** setting, which picks the role a new user gets when added from the element.

Some element types don't use all five levels. The configuration form of each element shows the levels that element type supports.

![Role permission levels in an element form: Admin in Level 1, Developer in Level 2, Product Designer and Marketing in Level 3, an empty Assignable Roles box, and five roles in Hidden Roles](/img/elements/permission-levels-full.png)

## Assign roles to levels

1. Open the element in the [Elements](https://app.permit.io/elements) screen.
2. Under **Role permission levels**, drag each role from **Hidden Roles** to the level that role should have.
3. Click **Save**.
4. In the **End User Preview**, select each level to confirm what users with that level see. See [Preview an element](/embeddable-uis/user-preview).
