The Permit.io C++ SDK is an API client for the Permit API, generated with OpenAPI Generator. This page is for C++ developers who want to call the Permit API from C++. The page links to the SDK repository and lists the build requirements. The page doesn't include install or usage steps.

## Get the C++ SDK

The SDK source, generated API classes, and a usage example are in the [permitio/permit-cpp](https://github.com/permitio/permit-cpp) repository on GitHub.

The repository README lists these requirements to build the client library:

- CMake 3.2 or later
- Qt
- A C++ compiler

## Build the C++ SDK

The `client` directory of the repository holds a CMake project that builds the API client as a library. Clone the repository and build the project:

```bash
git clone https://github.com/permitio/permit-cpp.git
cmake -S permit-cpp/client -B permit-cpp/build
cmake --build permit-cpp/build
```

The build succeeds when `cmake --build` reports no errors and writes a `client` library into `permit-cpp/build`. The CMake project calls `find_package` for `Qt5Core`, `Qt5Network`, and `Qt5Gui`, so the Qt5 development packages must be installed before you run `cmake`.

The C++ SDK is not included in the [SDK feature parity table](/sdk/sdks-overview).
