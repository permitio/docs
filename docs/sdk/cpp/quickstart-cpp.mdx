The Permit.io C++ SDK is an API client for the Permit API, generated with OpenAPI Generator. This page is for C++ developers who want to call the Permit API from C++. The page links to the SDK repository and lists the build requirements. The page doesn't include install or usage steps.

## Get the C++ SDK

The SDK source, generated API classes, and a usage example are in the [permitio/permit-cpp](https://github.com/permitio/permit-cpp) repository on GitHub.

The repository README lists these requirements to build the client library:

- CMake 3.2 or later
- Qt
- A C++ compiler

The C++ SDK is not included in the [SDK feature parity table](/sdk/sdks-overview).

## Get help with the C++ SDK

Ask questions and send feedback in the [Permit.io Slack community](https://io.permit.io/slack).
