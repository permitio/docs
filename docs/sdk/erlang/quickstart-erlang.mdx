The Permit.io Erlang SDK repository contains Erlang code generated with OpenAPI Generator from the Permit API specification. This page is for Erlang developers who want to work with the Permit API from Erlang. The page links to the repository and describes its contents. The page doesn't include install or usage steps.

## Get the Erlang SDK

The generated code is in the [permitio/permit-erlang](https://github.com/permitio/permit-erlang) repository on GitHub. The repository README describes the code as an Erlang server stub that depends on [Cowboy](https://github.com/ninenines/cowboy), and gives setup steps that use `erlang.mk`.

## Set up the Erlang server stub

The README sets up the stub inside an `erlang.mk` application. Create the application first:

```bash
mkdir http_server && cd http_server
wget https://erlang.mk/erlang.mk
make -f erlang.mk bootstrap bootstrap-rel
```

Then add the `cowboy`, `jesse`, and `jsx` dependencies to the generated `Makefile`, copy the generated Erlang files (including the `priv` folder) into the application, start the stub with `openapi_server:start/2`, and run `make`. For the exact `Makefile` contents and startup steps, see the **Getting started** section of the [permit-erlang README](https://github.com/permitio/permit-erlang#getting-started).

The Erlang SDK is not included in the [SDK feature parity table](/sdk/sdks-overview).
