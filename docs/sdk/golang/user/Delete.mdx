# Delete

Delete a user with specific user key or id.

### Parameters
`ctx` -  The context of the request.<br/>
`userKey` - The Key of the user. This is the unique key of the user.<br/>

### Implementation

```go
err := Permit.Api.Users.Delete(ctx, "user-key")
```
