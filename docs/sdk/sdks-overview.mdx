Compare which Permit.io features each SDK supports before you choose an SDK or plan a migration between languages. This reference is for developers who call Permit from application code.

## SDKs in the feature parity table

The feature parity table covers six SDKs and the Terraform provider. Each quickstart installs the SDK and runs a first permission check.

| Language | Quickstart | Source repository |
|---|---|---|
| Node.js | [Check permissions with the Node.js SDK](/sdk/nodejs/quickstart-nodejs) | [permitio/permit-node](https://github.com/permitio/permit-node) |
| Go | [Check permissions with the Go SDK](/sdk/golang/quickstart-golang) | [permitio/permit-golang](https://github.com/permitio/permit-golang) |
| .NET | [Check permissions with the .NET SDK](/sdk/dotnet/quickstart-dotnet) | [permitio/permit-dotnet](https://github.com/permitio/permit-dotnet) |
| Java | [Check permissions with the Java SDK](/sdk/java/quickstart-java) | [permitio/permit-java](https://github.com/permitio/permit-java) |
| Python | [Check permissions with the Python SDK (asyncio)](/sdk/python/quickstart-python), [Check permissions with the Python SDK (sync)](/sdk/python/quickstart_python_sync) | [permitio/permit-python](https://github.com/permitio/permit-python) |
| Ruby | [Check permissions with the Ruby SDK](/sdk/ruby/quickstart-ruby) | [permitio/permit-ruby](https://github.com/permitio/permit-ruby) |
| Terraform | [Terraform provider](/integrations/infra-as-code/terraform-provider) | Not an SDK. See [Terraform provider support](#terraform-provider-support). |

The table doesn't cover the [PHP](/sdk/php/quickstart-php), [Kotlin](/sdk/kotlin/quickstart-kotlin), [Erlang](/sdk/erlang/quickstart-erlang), and [C++](/sdk/cpp/quickstart-cpp) SDKs, which are API clients generated from the Permit API specification.

:::info Check the SDK source for the latest support
SDK releases add features over time, so a row in this table can lag behind the latest release. Before you depend on a feature, check the SDK's source repository or reference documentation.
:::

## Terraform provider support

The Terraform provider is not a full SDK. The Terraform provider manages Permit.io policy objects, such as resources, roles, and condition sets, as Terraform resources. Features that run at request time, such as permission checks, don't fit the Terraform model, so the table marks them as not compatible (🟤).
