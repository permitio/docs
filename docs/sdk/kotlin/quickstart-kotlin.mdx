The Permit.io Kotlin SDK is an API client for the Permit API, generated with OpenAPI Generator. This page is for Kotlin developers who want to call the Permit API from Kotlin. The page links to the SDK repository and lists the build requirements. The page doesn't include install or usage steps.

## Get the Kotlin SDK

The SDK source and generated API classes are in the [permitio/permit-kotlin](https://github.com/permitio/permit-kotlin) repository on GitHub.

The repository README lists these requirements:

- Kotlin 1.6.10
- Gradle 7.5

To build the library, follow the build steps in the repository README.

The Kotlin SDK is not included in the [SDK feature parity table](/sdk/sdks-overview).

## Get help with the Kotlin SDK

Ask questions and send feedback in the [Permit.io Slack community](https://io.permit.io/slack).
