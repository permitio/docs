## 4. Confirm the check in the audit log

Open the **[Audit Log](https://app.permit.io/audit-log)** screen in the Permit dashboard. Each permission check from your application appears as an entry with the user, the action, the resource, and the decision.

If the check doesn't appear in the audit log, see [Troubleshoot audit logs](/how-to/use-audit-logs/troubleshooting).
