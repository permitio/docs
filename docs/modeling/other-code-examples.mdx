Find an open-source example repository that shows Permit.io authorization in the framework, language, or stack you use. This page is for developers who want working code to read or copy before they add permission checks to their own app. For guided walkthroughs of full demo apps, see the other pages in this section, such as [Food Delivery System Example](/modeling/food-delivery-system-example-using-nuxt).

## What the examples cover \{#why-these-examples}

Each repository is a runnable app or integration maintained in the [permitio GitHub organization](https://github.com/permitio). The examples show how to:

- Call `permit.check()` from a backend framework or middleware.
- Model role-based access control (RBAC), attribute-based access control (ABAC), and relationship-based access control (ReBAC) policies, and sync users, resources, and relationships to Permit.
- Show or hide frontend features with the `permit-fe-sdk` and CASL.
- Run the policy decision point (PDP) on different platforms.
- Manage policy as code with GitOps, Open Policy Agent (OPA) Rego, and the Open Policy Administration Layer (OPAL).
- Add permission checks to AI agents and retrieval pipelines.

Typical topics in the list:

| Topic | Examples of what you find |
|---|---|
| Backend frameworks | Express, Fastify, FastAPI, Spring Boot, Go, and Java apps that call `permit.check()` |
| Frontend frameworks | React, Angular, and Vue apps that toggle UI with `permit-fe-sdk` and CASL |
| Full demo apps | Galactic Health Corporation, Pink Mobile, the Nuxt food delivery app, the Mesa Verde banking demo, Fleet Ops, the Great Eagle Logistics portal, and fine-grained bot protection, in the `permitio/examples` repository |
| Deployment | PDP deployment examples for different platforms |
| Policy as code | Example OPAL policy repositories, generated policy code, and Rego-based ReBAC |
| AI agents | LangChain, Langflow, and PydanticAI integrations |

## Full demo apps in the examples repository \{#examples-repository}

The [permitio/examples](https://github.com/permitio/examples) repository holds full demo apps, one per folder, including the seven below. Each of these folders runs with Docker Compose and a local PDP, needs only a Permit environment API key, and has a README with the steps:

| Folder | What it shows | Walkthrough |
|---|---|---|
| [galactic-health-corporation](https://github.com/permitio/examples/tree/main/galactic-health-corporation) | A healthcare portal with caregiver delegation, member groups, and pilot groups | [Healthcare Demo Application](/modeling/rebac-GHC) |
| [pink-mobile](https://github.com/permitio/examples/tree/main/pink-mobile) | A mobile plan app with manager, representative, and customer personas | [Teleco Demo Application](/modeling/pink-mobile) |
| [nuxt-food-delivery](https://github.com/permitio/examples/tree/main/nuxt-food-delivery) | A multi-city food delivery app with RBAC, ABAC, and ReBAC on the same actions | [Food Delivery System Example](/modeling/food-delivery-system-example-using-nuxt) |
| [mesa-verde-banking](https://github.com/permitio/examples/tree/main/mesa-verde-banking) | A banking app with multi-tenant RBAC, wire transfer rules, and approval flows | [Banking app example: Mesa Verde](/modeling/mesa-verde) |
| [fleet-ops-demo](https://github.com/permitio/examples/tree/main/fleet-ops-demo) | A multi-tenant fleet app on the Go SDK with nested organizations, partner access, attribute-based sets, custom Rego rules loaded through GitOps, and Terraform for the schema | [Multi-tenant fleet example: Fleet Ops](/modeling/fleet-ops) |
| [permit-portal-demo](https://github.com/permitio/examples/tree/main/permit-portal-demo) | A logistics business portal with onboarding approvals, time-boxed collaborator access, and a panel that shows each Permit check and write | [Logistics portal example: Great Eagle](/modeling/logistics-portal) |
| [fine-grained-bot-protection](https://github.com/permitio/examples/tree/main/fine-grained-bot-protection) | An Express app that gives humans and bots different access, with ABAC on a `botType` user attribute | [Bot protection example: humans and AI bots](/modeling/bot-protection) |
