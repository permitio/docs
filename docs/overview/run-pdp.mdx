Your application sends permission checks to a [Policy Decision Point](/overview/how-does-it-work#the-policy-decision-point-pdp) (PDP),
the microservice that evaluates your policy. You can use either a **managed Cloud PDP** hosted by Permit.io
([see capabilities](/concepts/pdp/cloud-pdp-capabilities)),
or a **container PDP** you deploy yourself.

<TabItem value="container" label="Container PDP" default>

Follow these steps to **install** and **run** the PDP container on your machine.

### Pulling PDP container from Docker Hub

If you don't have Docker yet, **[install Docker](https://docs.docker.com/get-docker/)** first.

```
docker pull permitio/pdp-v2:latest
```

### Running the container

**Replace** `<YOUR_API_KEY>` with your environment **API key**.

```
docker run -it -p 7766:7000 --env PDP_DEBUG=True --env PDP_API_KEY=<YOUR_API_KEY> permitio/pdp-v2:latest
```

:::info
Your PDP container is running. To check its status, run `docker ps` in your terminal.
:::

</TabItem>
<TabItem value="cloud" label="Cloud PDP">

To use the Cloud PDP, pass the Cloud PDP URL when you initialize the Permit SDK ([see Cloud PDP Capabilities](/concepts/pdp/cloud-pdp-capabilities)).

:::danger REMEMBER
The Cloud PDP is a **managed, production-ready** PDP hosted by Permit.io.

The Cloud PDP can be used in production for many workloads. For latency-sensitive deployments, you may still want to deploy a **container PDP** close to your application.

**ABAC is not supported** on the Cloud PDP. Deploy a container PDP if you need ABAC or container-only helper APIs such as all-tenants checks or local enforcement APIs. 
For the full list of supported features, see [Cloud PDP Capabilities](/concepts/pdp/cloud-pdp-capabilities).

:::

```js
// This line initializes the SDK and connects your app
// to the Permit.io Cloud PDP.

const permit = new Permit({
  pdp: "https://cloudpdp.api.permit.io",
  // your API Key
  token: "[YOUR_API_KEY]",
});
```
