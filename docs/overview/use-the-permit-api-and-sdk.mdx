Connect your application to Permit.io: install and initialize the Permit SDK, find your project and environment IDs, and create a role with your first API call. This tutorial is for developers new to Permit and uses the Node.js SDK (`permitio`).

## Prerequisites

- A Permit.io account. Sign in at [app.permit.io](https://app.permit.io/).
- Node.js and npm or Yarn installed. For other languages, see the [SDKs overview](/sdk/sdks-overview).

## Permit API and SDK reference \{#our-api--sdk-reference}

The [Permit API reference](https://api.permit.io/scalar) documents every endpoint, with request and response schemas. The SDK calls the same API.

## Initialize the Permit object \{#initializing-the-permit-object}

Create a `Permit` object, your interface to the Permit API and the policy decision point (PDP). Replace `[YOUR_API_KEY]` with the API key you copied. The `pdp` option points at the managed Cloud PDP. To use a PDP container instead, see [Run the PDP](/overview/run-pdp).

<CodeBlock folderPath="/walkthroughs/first-policy-check/initialize" />

:::tip Optional SDK settings
To make the SDK emit debug logs, add this `log` option to the object you pass to `new Permit()`:

```js
log: {
  level: "debug",
},
```

By default, `permit.check()` returns `false` on a timeout or network error. To make the SDK throw an error instead, add this option:

```js
throwOnError: true,
```
:::
