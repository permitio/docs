## Prerequisites

- A Permit.io account with at least one policy. If you don't have a policy yet, complete the [Quickstart](/quickstart).
- Docker, if you run the policy decision point (PDP) as a container. See [Install Docker](https://docs.docker.com/get-docker/).

## 1. Get your environment API key \{#1-get-your-permit-environment-api-key}

The SDK and the PDP authenticate with Permit using an environment API key. Each API key belongs to one environment.

1. In the [Permit dashboard](https://app.permit.io/), open the **Projects** screen.
2. Find the [project](/overview/glossary#projects) and the [environment](/overview/glossary#environment) you want to connect to.
3. On the environment card, click the ![Three dots menu icon](/ui-videos/getting-started/connecting-your-app/dots.png) icon in the top-right corner.
4. Click **Copy API Key**.

<img
  src="/img/updated/quickstart/sdk-key-1.png"
  alt="Projects screen with the environment card menu open and Copy API Key highlighted"
  data-zoomable
/>

:::note Copy the API key from the user menu
You can also copy the API key of the active environment from **User Menu > Copy Environment Key**.

<img
  src="/img/updated/quickstart/sdk-key-2.png"
  alt="User menu open with Copy Environment Key highlighted"
  data-zoomable
/>
:::

:::info The user menu copies the active environment's key
The API key you copy from the user menu belongs to the active environment in the sidebar.
If you switch the active environment and click **Copy Environment Key** again, you copy a **different** API key: the key of the newly active environment.
:::

:::warning Keep the API key out of source control
Anyone with your environment API key can change that environment's policy and data through the Permit API. Load the API key from an environment variable or a secret store, and don't commit the API key to your repository.
:::

## 2. Set up your policy decision point (PDP) \{#2-setup-your-pdp-policy-decision-point-container}

Your application sends each permission check to a [policy decision point (PDP)](/overview/how-does-it-work#the-policy-decision-point-pdp),
the service that evaluates the check against your policy. Use the managed Cloud PDP that Permit.io runs, or run the PDP as a Docker container on your machine.

The SDK examples on this page connect to a container PDP at `http://localhost:7766`. To use the Cloud PDP, set the SDK's PDP URL to `https://cloudpdp.api.permit.io` instead.

<Tabs groupId="pdp">
<TabItem value="cloud" label="Cloud PDP" default>

The Cloud PDP needs no installation. Pass the Cloud PDP URL when you initialize the Permit SDK. The following Node.js example shows the shape. The SDK install step further down shows the same setting in this page's language. Replace `[YOUR_API_KEY]` with your environment API key:

```js
// This line initializes the SDK and connects your app
// to the Permit.io Cloud PDP.

const permit = new Permit({
  pdp: "https://cloudpdp.api.permit.io",
  // your API Key
  token: "[YOUR_API_KEY]",
});
```

:::note Cloud PDP policy models
The Cloud PDP is a managed service that Permit.io runs. The Cloud PDP supports RBAC (role-based access control) and ReBAC (relationship-based access control) policies. The Cloud PDP does not support ABAC (attribute-based access control) policies, so the ABAC examples on this page need a container PDP.

For capabilities, limits, and when to choose each PDP type, see [Cloud PDP capabilities](/concepts/pdp/cloud-pdp-capabilities).
:::

</TabItem>
<TabItem value="container" label="Container PDP">

Pull and run the `permitio/pdp-v2` container image. Docker must be installed and running.

### 1. Pull the PDP container from Docker Hub \{#1-pull-our-pdp-container-from-docker-hub}

```bash
docker pull permitio/pdp-v2:latest
```

### 2. Run the PDP container \{#2-run-the-container}

Replace `<YOUR_API_KEY>` with the environment API key you copied in [1. Get your environment API key](#1-get-your-permit-environment-api-key), then run:

```bash
docker run -it -p 7766:7000 --env PDP_DEBUG=True --env PDP_API_KEY=<YOUR_API_KEY> permitio/pdp-v2:latest
```

| Option | Meaning |
|---|---|
| `-p 7766:7000` | Maps port `7766` on your machine to port `7000` inside the container. The SDK sends checks to `http://localhost:7766`. |
| `PDP_API_KEY` | The environment API key. The PDP uses the API key to load that environment's policy and data from Permit. |
| `PDP_DEBUG=True` | Turns on debug logging in the container output. |

To confirm the PDP container is running, run `docker ps` in a second terminal. The output lists a container from the `permitio/pdp-v2:latest` image with `0.0.0.0:7766->7000/tcp` in the `PORTS` column.

For more PDP options, see [Run the PDP](/overview/run-pdp).
