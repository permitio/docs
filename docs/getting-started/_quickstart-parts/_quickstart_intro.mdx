## 1. Get your Permit Environment API Key

- In the [Permit Dashboard](https://app.permit.io/), navigate to the Projects screen.
- Find the [Project](/overview/glossary#projects) and [Environment](/overview/glossary#environment) you want to connect to.
- Click the ![Dots](/ui-videos/getting-started/connecting-your-app/dots.png) icon on the top right of the environment card.
- Click Copy API Key.

  src="/img/updated/quickstart/sdk-key-1.png"

  data-zoomable
/>

::::note
You can also copy the API key of the active environment from **User Menu > Copy Environment Key**.

<img
  src="/img/updated/quickstart/sdk-key-2.png"

/>
::::

::::info Remember
The API key you copy from the user menu belongs to the active environment in the sidebar.
If you switch the active environment and click **Copy Environment Key** again, you copy a **different** API key: the key of the newly active environment.
::::

## 2. Setup your PDP (Policy Decision Point) Container

Your application sends permission checks to a [policy decision point (PDP)](/overview/how-does-it-work#the-policy-decision-point-pdp),
the microservice that evaluates your policy. Run the PDP as a Docker container,
or use the managed Cloud PDP that Permit.io runs for you.

<Tabs groupId="pdp">
<TabItem value="cloud" label="Cloud PDP" default>

To use the Cloud PDP, pass the Cloud PDP URL when you initialize the Permit SDK.

::::note
Cloud PDP is a **managed, production-ready** service that Permit.io runs for you. It supports **RBAC and ReBAC**
authorization models, but **does not support ABAC**.

For more details on capabilities, limits, and when to use Cloud PDP vs. a container PDP, see
[Cloud PDP Capabilities](/concepts/pdp/cloud-pdp-capabilities).

::::

```js
// This line initializes the SDK and connects your app
// to the Permit.io Cloud PDP.

const permit = new Permit({
  pdp: "https://cloudpdp.api.permit.io",
  // your API Key
  token: "[YOUR_API_KEY]",
});
```

</TabItem>
<TabItem value="container" label="Container PDP">

Follow these steps to **install** and **run** the PDP container on your machine.

### 1. Pull our PDP container from Docker Hub

If you don't have Docker yet, **[install Docker](https://docs.docker.com/get-docker/)** first.

```
docker pull permitio/pdp-v2:latest
```

### 2. Run the container

**Replace** `<YOUR_API_KEY>` with the API key you copied in the previous step.

```
docker run -it -p 7766:7000 --env PDP_DEBUG=True --env PDP_API_KEY=<YOUR_API_KEY> permitio/pdp-v2:latest
```

::::info
Your PDP container is running. To check its status, run `docker ps` in your terminal.

Next, add the Permit SDK to **[your app](/overview/glossary)** or use the demo example below.
