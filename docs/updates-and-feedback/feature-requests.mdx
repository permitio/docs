Ask the Permit.io team for a capability, or add your vote to a request someone else opened. This page is for developers and technical decision makers who need something Permit does not do yet.

## Before you submit a request

- Confirm the capability has not already shipped. See [Changelog](/updates-and-feedback/changelog).
- Confirm Permit is not already building it. See [Roadmap](/updates-and-feedback/roadmap).

## Submit or vote on a request

The Permit.io feature requests board runs on Canny. Each post has a title, a description, a vote count, and comments. Sort the list by **Trending**, **Top**, or **New**, and filter it by status: **Under Review**, **Planned**, **In Progress**, or **Complete**.

1. Open the [Permit.io feature requests board on Canny](https://permitio.canny.io/feature-requests).
2. Search the board for a request that matches your need. A status filter you applied earlier hides posts in other statuses, so remove the filters before you decide that no post matches.
3. Vote on the matching request, and comment with your use case. If no request matches, choose **Create** and describe the authorization model, deployment, or integration that needs the capability.

Your request is submitted when it appears on the board with your vote on it. Creating, voting on, and commenting on requests requires a Canny account.

:::note Two boards collect Permit.io requests
Canny holds the public request backlog. Productlane holds the published roadmap, with the ideas the Permit team has put on it. The Permit team links a reviewed request to a roadmap idea, so a request that Permit accepts can appear on the [Productlane roadmap](https://permit.productlane.com/roadmap) as well. Post on Canny, then follow the status on whichever board shows your request.
:::

## Escalate a request that blocks you

A board post is a public request, not a support ticket. When a missing capability blocks a delivery date, email [support@permit.io](mailto:support@permit.io) with your use case and the board post link, or [book a call with Permit](https://www.permit.io/demo).
