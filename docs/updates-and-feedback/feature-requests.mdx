Ask the Permit.io team for a feature, or add your vote to an existing request. Use the feature requests board when Permit is missing something your authorization model or deployment needs.

## What the feature requests board contains

The board lists requests from Permit users, each with a title, a description, votes, and comments. You can sort the list by trending, top, or new requests, and filter it by status: under review, planned, in progress, or complete.

## Submit or vote on a feature request

1. Open the [Permit.io feature requests board on Canny](https://permitio.canny.io/feature-requests).
2. Search the board for an existing request that matches your need.
3. Vote on or comment on the matching request. If no request matches, create a request and describe your use case.

Creating, voting on, and commenting on requests requires you to sign in to Canny.
