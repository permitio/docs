The Permit.io changelog lists released product updates. Check it to find out when an API, SDK method, or Permit Elements feature became available, before you upgrade or plan work that depends on it.

## What the changelog contains

Each changelog entry describes one release, with a title and a description of the change. Past entries cover items such as bulk permission checks, the `getUserPermissions` and `getAuthorizedUsers` methods, the Access Requests API and element, and attribute-based access control (ABAC) object match operators.

## Open the changelog

Read the [Permit.io changelog on Canny](https://permitio.canny.io/changelog).
