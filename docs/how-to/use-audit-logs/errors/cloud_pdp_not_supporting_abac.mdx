---
title: Cloud PDP does not support ABAC
description: "Fix the Cloud PDP does not support ABAC error by running ABAC checks against a self-hosted PDP instead."
---

This error occurred because you attempted to verify ABAC permissions using Permit Cloud PDP, which unfortunately does not support
ABAC functionality. However, you can effectively utilize ABAC with the
[Permit Production PDP](/how-to/deploy/deploy-to-production).
